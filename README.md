# plant buddy landing page

this is a responsive landing page for a plant care community — built with html, css and javascript. clean, green, and gentle on all screen sizes.

## original design source

🎨 [plant buddy landing page by nickelfox design](https://www.figma.com/community/file/1015147614988696404/plant-buddy-landing-page)

## key features

- ✅ fully responsive layout — adapts from mobile to desktop with a mobile burger menu.
- ✅ accessible markup — skip link, aria labels, focus-visible outlines, reduced-motion support.
- ✅ scroll reveal animations — elements fade in via intersectionobserver as you scroll.
- ✅ animated stat counters — numbers count up with eased easing when they enter the viewport.
- ✅ sticky header — shrinks on scroll with a blurred backdrop.
- ✅ back-to-top button — appears after scrolling, smooth-scrolls to the top.
- ✅ subscribe form — inline email form with a success message on submit.

## what this project practices

- building a landing page from scratch without frameworks.
- organizing css with custom properties (design tokens) for colors, spacing, radius, and motion.
- using intersectionobserver for scroll-based reveals and counters.
- keeping javascript minimal and dependency-free.
- writing semantic html with accessibility in mind.

## how to run

- make sure the `css/`, `js/`, and `images/` folders sit next to `index.html`.
- open `index.html` in a browser.
- fonts load from google fonts (fraunces + inter) via cdn.

## notes

- the page includes a header, hero, quote, stats, place cards, cta section, and footer.
- all icons are inline svg — no icon library required.
- the subscribe form is front-end only; wire it to your backend or email service to collect addresses.
- placeholder images in `images/` can be swapped for real photography.
